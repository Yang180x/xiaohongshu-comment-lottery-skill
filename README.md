# 小红书评论区寄样用户筛选 Skill

基于小红书笔记评论区，自动读取公开评论与用户主页信息，通过多维度分析筛选真正适合 **寄样、体验官招募、产品试用、种草合作** 的目标用户，并自动生成正式名单、备选名单和完整筛选明细 Excel 报告。

> 这不是一个随机抽奖工具，也不是简单按照粉丝数量排序的工具。
> 它的核心目标是：**从评论区中找到真正有需求、与产品匹配、具备内容价值的潜在体验用户。**

---

## ✨ 这个 Skill 能做什么？

你只需要提供：

* 一篇小红书笔记链接
* 希望筛选的人数，例如 `10 人`

AI Agent 即可通过 BrowserSkill 操作你已经登录小红书的真实浏览器，完成从 **笔记分析 → 评论读取 → 用户筛选 → 主页分析 → 排名 → Excel 报告生成** 的完整流程。

例如：

```text
帮我从这篇小红书笔记的评论区筛选 10 位适合寄样的用户：

https://www.xiaohongshu.com/explore/xxxx
```

Skill 会自动完成后续工作。

# 🧠 筛选逻辑

本 Skill **不会简单按照粉丝数量筛选用户**。

核心优先级固定为：

> **真实需求 > 评论相关度 > 产品匹配度 > 账号质量 > 内容价值 > 粉丝数量**

其中：

### 1. 真实需求

判断用户是否真正对产品存在需求、兴趣或者明确使用场景。

例如：

```text
最近刚好在找这种防晒，油皮夏天真的不知道买什么。
```

通常会比：

```text
好漂亮！
```

具有更高筛选价值。

---

### 2. 评论相关度

判断评论是否真正围绕：

* 产品
* 功效
* 使用场景
* 用户痛点
* 购买需求
* 产品特点

展开。

过滤：

* 纯表情
* 无意义评论
* 广告
* 引流
* 互粉
* 无关聊天
* 明显机器评论

---

### 3. 产品匹配度

结合笔记内容自动分析产品画像，再判断评论用户是否符合目标产品。

例如：

```text
产品：敏感肌修护面霜
```

那么评论中：

```text
换季脸特别容易泛红，一直找不到合适的修护面霜。
```

通常属于高匹配用户。

---

### 4. 账号质量

进入候选用户主页进一步分析：

* 账号是否真实活跃
* 是否存在正常笔记
* 是否长期空号
* 是否疑似营销号
* 是否存在明显异常账号行为
* 内容是否具有持续性

---

### 5. 内容价值

分析用户历史公开笔记，例如：

* 是否有相关品类内容
* 是否有真实使用分享
* 是否具备一定内容表达能力
* 图片 / 视频内容质量
* 笔记互动情况
* 内容方向是否与产品相关

对于寄样活动来说：

**会正常分享产品体验的真实消费者，往往比单纯粉丝数量更重要。**

---

### 6. 粉丝数量

粉丝数量只作为辅助参考指标。

不会出现：

```text
粉丝越多 = 排名越高
```

这样的简单逻辑。

一个只有 300 粉丝，但长期分享真实护肤体验的用户，可能会排在一个 2 万粉丝但内容完全不相关的用户前面。

# 🔄 工作流程

整个任务分为 7 个阶段：

```text
用户输入小红书链接 + 目标人数
              ↓
阶段 1：分析目标笔记
              ↓
      建立产品画像
              ↓
阶段 2：完整读取公开评论区
              ↓
阶段 3：评论清洗 + 评论评分
              ↓
阶段 4：建立预筛候选池
              ↓
      默认约目标人数 × 2
              ↓
阶段 5：进入用户主页分析
              ↓
      不合格用户动态递补
              ↓
阶段 6：综合评分与排名
              ↓
       正式名单 + 备选名单
              ↓
阶段 7：生成 Excel 筛选报告
```

---

# 🔍 阶段 1：笔记分析

首先读取目标小红书笔记，包括：

* 标题
* 正文
* 产品名称
* 产品类型
* 卖点
* 使用场景
* 目标用户
* 用户痛点
* 内容主题

AI 会自动建立一个：

```text
产品 / 活动用户画像
```

后面的评论筛选都围绕该画像进行。

---

# 💬 阶段 2：评论区读取

通过腾讯开源的 **BrowserSkill** 操作你已经登录的小红书浏览器。

自动完成：

* 打开目标笔记
* 展开评论区
* 持续滚动
* 展开更多评论
* 读取公开评论
* 读取评论用户
* 收集候选用户主页入口

尽可能完整地获取当前浏览器可访问的公开评论数据。

---

# 🧹 阶段 3：评论清洗

自动过滤低价值评论，例如：

```text
😍😍😍
```

```text
来了
```

```text
好看
```

```text
互关
```

```text
看看我主页
```

以及：

* 广告
* 引流
* 无关内容
* 重复评论
* 明显营销内容
* 缺乏实际信息的评论

保留真正具有用户需求和分析价值的评论。

---

# 👥 阶段 4：建立候选池

假设你需要：

```text
10 位寄样用户
```

Skill 不会只筛选 10 位。

默认会先建立约：

```text
20 位候选用户
```

再进行主页深度分析。

这样可以避免：

* 用户主页异常
* 用户内容不匹配
* 空号
* 营销号
* 内容质量过低

导致最后人数不足。

---

# 🏠 阶段 5：用户主页分析

对于进入候选池的用户，继续读取其公开主页信息。

可能包括：

* 用户昵称
* 用户简介
* 粉丝数量
* 获赞与收藏
* 公开笔记数量
* 近期笔记
* 内容方向
* 内容类型
* 相关产品内容
* 笔记互动
* 账号活跃程度

然后进行第二轮筛选。

如果某位候选用户不符合要求，会自动继续从评论候选池中递补下一位。

---

# 🏆 阶段 6：综合排名

最终根据六维优先级：

```text
真实需求
   ↓
评论相关度
   ↓
产品匹配度
   ↓
账号质量
   ↓
内容价值
   ↓
粉丝数量
```

生成最终排名。

例如用户要求：

```text
筛选 10 位
```

最终默认输出：

```text
正式名单：10 位

备选名单：5 位
```

备选人数可以根据任务调整。

---

# 📊 最终产出

任务完成后，会生成一份 Excel 筛选报告。

默认包含 **3 个 Sheet**：

| Sheet  | 内容                  |
| ------ | ------------------- |
| 正式名单   | 最终推荐进行寄样 / 体验官合作的用户 |
| 备选名单   | 正式用户无法联系或拒绝合作时的递补用户 |
| 评论筛选明细 | 候选用户的完整评论、评分与筛选过程   |

---

## Sheet 1：正式名单

用于运营人员直接进行后续联系。

可能包含：

| 字段     | 说明             |
| ------ | -------------- |
| 排名     | 综合推荐排名         |
| 用户昵称   | 小红书昵称          |
| 用户主页   | 用户主页链接         |
| 原始评论   | 用户在目标笔记下的评论    |
| 粉丝数    | 用户粉丝数量         |
| 用户简介   | 用户主页简介         |
| 账号定位   | AI 分析的账号内容方向   |
| 真实需求评分 | 用户需求强度         |
| 评论相关度  | 评论与产品的相关程度     |
| 产品匹配度  | 用户与产品目标人群的匹配程度 |
| 账号质量   | 用户账号质量         |
| 内容价值   | 用户内容创作价值       |
| 综合评分   | 最终综合评分         |
| 推荐理由   | 为什么推荐该用户       |
| 风险备注   | 可能需要人工关注的问题    |

---

## Sheet 2：备选名单

默认保留约 **5 位备选用户**。

当正式名单出现：

* 无法联系
* 用户拒绝
* 地址问题
* 档期问题
* 品牌人工复审不通过

等情况时，可以直接从备选名单递补。

---

## Sheet 3：评论筛选明细

用于查看整个筛选过程。

包括：

* 用户
* 原始评论
* 评论分类
* 评论有效性
* 用户需求判断
* 产品匹配情况
* 评论评分
* 是否进入候选池
* 是否进入主页分析
* 最终筛选结果
* 淘汰原因

方便运营人员进行：

```text
人工复审
```

而不是只得到一个无法解释的 AI 黑盒名单。

# 🌐 为什么使用 BrowserSkill？

本项目使用腾讯开源项目：

[**Tencent/BrowserSkill**](https://github.com/Tencent/BrowserSkill)

BrowserSkill 可以让 AI Agent 操作你的**真实浏览器环境**。

也就是说：

```text
不是重新启动一个陌生浏览器
```

而是：

```text
AI Agent
   ↓
BrowserSkill
   ↓
你当前使用的 Chrome / Edge
   ↓
你已经登录的小红书账号
```

这样可以直接利用浏览器中已经存在的登录状态。

# ⚙️ 前置条件

使用本 Skill 前，需要完成以下准备工作。

## 1. 安装 BrowserSkill

项目地址：

https://github.com/Tencent/BrowserSkill

推荐直接让你的 AI Agent 按照 BrowserSkill 官方 Agent 安装说明执行：

```text
按照 https://raw.githubusercontent.com/Tencent/BrowserSkill/main/AGENT_INSTALL.md 的说明，

```

也可以手动安装。

### macOS / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh

bsk install-skill --yes
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.ps1 | iex

bsk install-skill --yes
```

---

## 2. 检查 BrowserSkill

安装完成后执行：

```bash
bsk doctor
```

检查 BrowserSkill 当前环境。

正常情况下，各项检查应显示：

```text
ok
```

或：

```text
na
```

如果：

```text
extension connected
```

显示失败，通常说明浏览器扩展还没有安装或者连接。

# 💡 核心设计理念

传统寄样筛选经常采用：

```text
评论区
 ↓
随机抽人
```

或者：

```text
评论区
 ↓
找粉丝最多的人
```

本 Skill 希望实现的是：

```text
评论区
   ↓
识别真实消费者需求
   ↓
分析产品匹配程度
   ↓
进入用户主页
   ↓
分析账号与内容
   ↓
筛选真正值得寄样的用户
   ↓
输出可解释的筛选报告
```

最终目标不是：

> **“找最大的账号。”**

而是：

> **“找到最适合这个产品的人。”**
