# 评分与筛选细则（执行参考）

本文档是 `小红书评论区寄样用户筛选` skill 的打分锚点与判定细则。执行 skill 时按此打分，保证不同批次结果口径一致。

## 一、评论评分锚点（100 分制）

### A. 笔记相关度（0–35）

| 分段 | 表现 |
|------|------|
| 28–35 | 评论直接围绕该产品：问功效、问肤质适配、问用法用量、谈自己的使用体验、问购买渠道/价格 |
| 18–27 | 围绕笔记主题但偏泛：如「夏天确实需要这种」「油皮看到这个走不动了」，有场景关联但未落到本品 |
| 8–17 | 与笔记弱相关：泛泛夸博主、只谈品类不谈产品、通用互动 |
| 0–7 | 与笔记无关、纯寒暄、跑题聊天 |

### B. 产品兴趣 / 需求强度（0–30）

| 分段 | 表现 |
|------|------|
| 24–30 | 强信号：询价、问哪里买、求链接、明确说「被种草了」「想试试」「已下单」、问是否适合自己（肤质/发质/体质） |
| 15–23 | 中信号：表达同类需求（「我就是大油皮」）、询问使用方式/频率/搭配、追问细节（成分/规格/保质期） |
| 6–14 | 弱信号：笼统表示喜欢、点赞式附和 |
| 0–5 | 无兴趣信号 |

加分项（叠加时向上取档）：主动询问购买渠道 +；主动询价 +；表达想试用 +；明确表示被种草 +。

### C. 用户需求匹配度（0–20）

| 分段 | 表现 |
|------|------|
| 16–20 | 评论透露的需求/肤质/场景/人群与笔记产品画像高度吻合 |
| 8–15 | 部分吻合，或需求泛化但方向一致 |
| 0–7 | 不匹配、无法判断 |

判断依据必须来自评论原文透露的信息（如「敏感肌可以吗」→ 敏感肌人群），不得臆测。

### D. 评论真实性（0–15）

| 分段 | 表现 |
|------|------|
| 12–15 | 语言自然、有具体细节（时间、场景、自身情况）、明显个人化表达 |
| 7–11 | 自然但简短，无模板痕迹 |
| 0–6 | 模板化、复制粘贴感、广告腔、机器人特征（句式整齐划一、多账号雷同） |

**长度不作为真实性依据。**「敏感肌可以吗？」「求链接」虽短但真实且高价值。

## 二、无效评论判定清单

排除项：

- 纯表情 / 哈哈哈 / 来了 / 路过 / 打卡 / 支持 / 666 / 蹲一个 / 求中
- 与笔记内容完全无关
- 明显广告、引流（含联系方式、引导加群、导购其他产品）
- 复制粘贴模板（多账号发布高度雷同内容）
- 疑似机器人评论
- 单纯与其他评论者聊天且与笔记无关

保留项（虽短但高价值）：

- 多少钱？/ 哪里买？/ 求链接
- 敏感肌可以吗？/ 适合油皮吗？/ 孕妇能用吗？
- 可以试试吗？/ 想要 / 已下单等明确兴趣表达

## 三、主页淘汰规则

直接淘汰：

- **非作者粉丝（硬性条件，最高优先级）**：主页关注按钮显示「关注」= 该用户未关注笔记作者 → 无论评论分与账号质量多好，一律淘汰并递补。按钮显示「相互关注」或「回关」= 是粉丝，正常保留。「已关注」/按钮不可见 → 记「无法确认」，保留不淘汰。前提：浏览器登录账号须为笔记作者账号。
- 明显营销号 / 广告号（简介带商务联系方式、内容全是商单）
- 批量搬运号（内容与多个账号雷同、无个人化痕迹）
- 机器人账号、空账号（无简介无笔记）
- 长期无内容（最近笔记距今超过约 6 个月且数量极少）
- 大量抽奖内容、明显薅羊毛账号（主页高频出现「中奖」「抽奖」「免费领」类笔记）
- 主页内容与产品完全无关且无生活分享价值
- 账号异常、无法正常访问且缺乏足够判断信息

降级（不淘汰但降低综合排名）：

- 内容活跃度一般（月更以下）
- 垂直度一般（泛生活内容为主，偶尔相关）
- 粉丝数极少且无内容沉淀（潜在传播价值低，但兴趣真实）

## 四、综合排名权重建议

最终排名 = 评论分（主导） + 主页质量（修正），建议权重：

| 维度 | 权重 |
|------|------|
| 评论综合分（A+B+C+D） | 55% |
| 主页垂类相关度 | 15% |
| 内容质量与活跃度 | 12% |
| 潜在种草价值 | 10% |
| 账号风险（负向） | 8% |

粉丝数仅在两人其余维度接近时作为辅助排序依据。

## 五、推荐理由写作规范

必须包含（尽量全部）：

1. 用户原始评论的核心内容（引用或转述）
2. 评论体现的具体需求
3. 与产品目标人群的匹配点
4. 主页定位与内容情况
5. 结论（正式/备选）

禁止：「账号不错」「用户质量高」「推荐寄样」「粉丝较多」等空泛描述。

合格示例见 SKILL.md 阶段 6。

## 六、数量场景速查

| 场景 | 处理 |
|------|------|
| 有效用户充足 | 预筛 ≈ 2×candidate_count，递补至满额 |
| 有效用户不足 2 倍但 ≥ candidate_count | 直接分析全部有效用户，凑满 candidate_count |
| 有效用户 > target_count 但 < candidate_count | 输出 target 正式 + 实际剩余备选，说明未强行补足 |
| 有效用户 ≤ target_count | 输出实际合格人数，明确说明 |
| 评论区几乎无有效评论 | 如实报告，不输出空壳名单，与用户协商换笔记或换方式 |
